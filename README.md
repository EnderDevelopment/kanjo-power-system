# Kanjō Power System

The Kanjō Power System is a Minecraft plugin that introduces a unique power system inspired by emotions and energy manipulation. This plugin allows players to generate and manipulate Kanjō Energy, which can be either Negative (damage, attack power, critical/offensive output) or Positive (defense, durability, health, restoration). The system includes various features such as countering, Kanjō skills, types, and abilities, providing a deep and immersive combat experience.

## Install

1. Download the plugin JAR file from the [releases page](https://github.com/EnderDevelopment/KanjoPowerSystem/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your server to load the plugin.

## Use

1. **Commands**:
   - `/kanjo energy`: Learn about Kanjō Energy.
   - `/kanjo counter`: Understand countering mechanics.
   - `/kanjo skill`: Explore the three Kanjō Skills.
   - `/kanjo type`: Discover the four Kanjō Types.
   - `/displayenergy`: Display your current Kanjō energy levels.

2. **Gameplay**:
   - Use the commands to learn about the Kanjō Power System.
   - Engage in combat to generate and manipulate Kanjō Energy.
   - Utilize the different Kanjō Types and Skills to enhance your gameplay experience.
